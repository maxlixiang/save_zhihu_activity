19k star 的私有文档搜索引擎 qmd，全部跑在本地  
qmd，18.9k ⭐，刚发 v2.1.0。定位是给 Markdown 笔记、会议记录、知识库做的本地搜索引擎，所有计算都在设备上完成，不上传任何数据。  
搜索策略是三层混合：  
BM25 做关键词精确匹配，向量嵌入做语义理解，LLM 做最终 rerank。  
三层叠在一起的效果比单用任何一层都好。本地模型用 node-llama-cpp 跑 GGUF 格式，不依赖外部 API。底层存储是 SQLite，关键词索引和向量嵌入都在一个数据库里，部署就是一个 npm 包的事。  
qmd 可以直接作为 MCP 服务给 AI Agent 提供检索，Claude Code 或其他 Agent 需要查文档时，一次请求就能拿到语义最相关的内容。对做 RAG 的人来说，这相当于一个开箱即用的本地检索后端。  
适合所有用 Markdown 管理知识的开发者。在做 RAG 系统的人可以直接拿 qmd 当本地检索层，省掉自己搭向量数据库的环节。

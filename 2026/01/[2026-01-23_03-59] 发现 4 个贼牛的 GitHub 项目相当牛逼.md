01
**一键克隆任何网站**
开源 5 天就获得了 10000+ 的 Star，**这个 GitHub 开源项目为啥这么火爆？**
它的项目描述：**在几秒钟将任何网站克隆重建为 React 应用。**
![](%5B2026-01-23_03-59%5D%20%E5%8F%91%E7%8E%B0%204%20%E4%B8%AA%E8%B4%BC%E7%89%9B%E7%9A%84%20GitHub%20%E9%A1%B9%E7%9B%AE%E7%9B%B8%E5%BD%93%E7%89%9B%E9%80%BC_%E5%9B%BE%E7%89%87/_1775634310206.jpg)
Open Lovable 是一个**开源的、基于 AI 的网站克隆神器**。
**只需要输入一个网址，几秒钟后，你就能得到一个可以运行的、现代 React 代码版本。**
它的背后原理很简单，通过 **Firecrawl** 爬虫工具去解析目标网址的结构，然后把解析的内容**丢给 AI 大模型**，然后 AI 就能够把解析的网页结构转成可运行的 React 版本了。
比如下面这个视频，直接把 firecrawl.dev 丢进去，不一会儿就获得了一个克隆的 firecrawl 网站。
![](%5B2026-01-23_03-59%5D%20%E5%8F%91%E7%8E%B0%204%20%E4%B8%AA%E8%B4%BC%E7%89%9B%E7%9A%84%20GitHub%20%E9%A1%B9%E7%9B%AE%E7%9B%B8%E5%BD%93%E7%89%9B%E9%80%BC_%E5%9B%BE%E7%89%87/_1775634310425.jpg)

**调教 Claude 成为编程大师**
发现了一个国外大神整理的 Claude 编程提示词，经过他亲身实践，**把这一段喂给 Claude ，能让你的 AI 编程之旅更加顺畅。**
![](%5B2026-01-23_03-59%5D%20%E5%8F%91%E7%8E%B0%204%20%E4%B8%AA%E8%B4%BC%E7%89%9B%E7%9A%84%20GitHub%20%E9%A1%B9%E7%9B%AE%E7%9B%B8%E5%BD%93%E7%89%9B%E9%80%BC_%E5%9B%BE%E7%89%87/_1775634313768.jpg)
让 Claude 编程更牛逼，给它的提示词需要有如下核心要点：
**① 开发哲学强调务实渐进：**
**遵循小步快跑原则，优先采用简单直接的解决方案，确保每次提交的代码均可编译、通过测试，避免过度设计，坚持“明确意图优于炫技代码”的理念。**
**② 流程规范注重计划与纪律：**
**将复杂任务拆分为3-5个阶段并记录计划文档；采用“理解→测试→实现→重构→提交”的标准化流程；关键问题上严格遵循“三次尝试后暂停分析”的纪律，需记录失败原因并探索替代方案。**
**③ 质量底线要求闭环验证：**
**所有提交必须通过编译和完整测试覆盖，遵循项目规范与一致性设计原则（如组合优于继承），并确保实现过程与计划文档同步更新，严禁绕过测试或提交未验证代码。**

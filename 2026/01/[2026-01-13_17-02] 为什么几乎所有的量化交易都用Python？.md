聚宽代码运行结果
不过，作为一个擅长**"本地化改造"**的人，我一直对不能脱离聚宽运行的代码心存遗憾。毕竟，策略、回测、数据，能本地运行才最自由、最高效。
所以，这次我把这套**市场宽度展示脚本做了本地化改造**，实现了：
* 无需登录聚宽平台
* 全流程在本地Python环境运行
* 数据源切换为TuShare（若数据量更大需切换到[miniQMT](https://zhida.zhihu.com/search?content_id=762651024&content_type=Answer&match_order=1&q=miniQMT&zhida_source=entity)）
**本地化改造关键点：**
1. **获取申万一级行业成分股**  
   聚宽使用`get_industry(stock, date)`，本地改造采用`Tushare`的pro.`index_member_all()`接口，轻松搞定申万一级行业全覆盖。
```
# 获取申万一级行业列表
# https://tushare.pro/document/2?doc_id=181
df = pro.index_classify(level='L1', src='SW2021')
s_industry = df[['index_code', 'industry_name']]
s_industry.index = s_industry['index_code']
s_industry = s_industry.drop(columns='index_code')
s_industry = s_industry.squeeze()
# 申万一级行业列表list
code_industry_all = s_industry.index.tolist()
s_industry.loc['999998'] = '全市场'
s_industry.loc['999999'] = '合计'
# 获取计算开始日期的股票列表
df = pro.daily(trade_date=trade_day[0])
stock_list = df['ts_code'].tolist()
# 获取所有一级分类信息，所含股票等    
df_all = []
for code in code_industry_all:
    df = pro.index_member_all(l1_code=code)
    df_all.append(df)
df_all = pd.concat(df_all)  
# 获取股票所在的行业
dict_stk_2_ind = {}
for stk in stock_list:
    df = df_all[df_all['ts_code'] == stk]
    if len(df) > 0:
        dict_stk_2_ind[stk] = df.iloc[0]['l1_code']
s_stk_2_ind = pd.Series(dict_stk_2_ind)
```
1. **获取股票历史收盘价**  
   聚宽内部调用简单，本地改造使用Tushare 的日线行情接口，不过需要对获取的数据自行进行复权。由于所需行情数据不多，数据量可控，完全可用Tushare。如果需求更大，就需要采用miniQMT等更强的本地行情系统。
```
# 获取股票行情数据
# pro.daily 单次只能提取6000条数据，因此需要控制好每次提取数据的股票数
price_all = []
stk_num = int(6000 / (count_+20)*0.99) # 每次提取多少只股票的历史行情
for i in range(0, len(stock_list), stk_num):
    idx_end = np.min([len(stock_list), i+stk_num])
    joined_str = ','.join(stock_list[i:idx_end]) # 单次提取行情的股票代码字符串
    df = pro.daily(ts_code=joined_str, start_date=since, end_date=until)
    price_all.append(df)
price_all = pd.concat(price_all)
price_all = price_all.set_index(['ts_code', 'trade_date'])
# pro.daily获取的行情是没有复权的，需要对数据进行复权
adjusted_list = []
for i, stk in enumerate(stock_list):
    df = price_all.loc[stk]
    df = df.sort_index() # 按日期对行进行重新排序
    df = adjust_price(df, 'front') # 对行情进行前复权
    df['ts_code'] = stk  # 添加回 ts_code 字段
    df['date'] = df.index
    df = df[['ts_code', 'close', 'date']]
    adjusted_list.append(df)  # reset_index 还原 trade_date，准备 concat
adjusted_list_all = pd.concat(adjusted_list)
```

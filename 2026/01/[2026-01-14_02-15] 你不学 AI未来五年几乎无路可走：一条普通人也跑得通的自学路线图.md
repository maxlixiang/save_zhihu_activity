## 阶段 1：数学复习（3 天搞定）
目标：只学够用的数学，而不是重新读一遍高数和线代。
### 第 1 天：线性代数核心
**学习路径：**
1. 看 3Blue1Brown《线性代数的本质》1–3 集
2. 用纸笔跟着推一遍“矩阵乘法”的几何直觉
3. 用 numpy 手写矩阵相关的小例子
你只需要理解这三件事：
### 矩阵是什么？
矩阵本质上是：**同时对一堆向量做线性变换的工具。一张图解决所有你需要了解的知识。**
**![](%5B2026-01-14_02-15%5D%20%E4%BD%A0%E4%B8%8D%E5%AD%A6%20AI%E6%9C%AA%E6%9D%A5%E4%BA%94%E5%B9%B4%E5%87%A0%E4%B9%8E%E6%97%A0%E8%B7%AF%E5%8F%AF%E8%B5%B0%EF%BC%9A%E4%B8%80%E6%9D%A1%E6%99%AE%E9%80%9A%E4%BA%BA%E4%B9%9F%E8%B7%91%E5%BE%97%E9%80%9A%E7%9A%84%E8%87%AA%E5%AD%A6%E8%B7%AF%E7%BA%BF%E5%9B%BE_%E5%9B%BE%E7%89%87/_1775634882333.jpg)**
**第 1 天自查练习：**
* 用 numpy 手写： 矩阵 × 向量
+ 矩阵 × 矩阵
+ 标量 × 矩阵
* 能用一句话解释：“为什么神经网络每一层可以看成矩阵乘法？”
只要你能做完这些，这一天就合格了。
### 第 2 天：微积分直觉
这里不要上来就啃高等数学，只要建立一件事的直觉：
梯度下降到底在干什么？
**学习路径：**
1. 找一条简单曲线，例如 y = x^2
2. 画出它的导数 dy/dx = 2x 的图像
3. 手写一个最简单的“单变量梯度下降”程序
同样一张图解决它。
**![](%5B2026-01-14_02-15%5D%20%E4%BD%A0%E4%B8%8D%E5%AD%A6%20AI%E6%9C%AA%E6%9D%A5%E4%BA%94%E5%B9%B4%E5%87%A0%E4%B9%8E%E6%97%A0%E8%B7%AF%E5%8F%AF%E8%B5%B0%EF%BC%9A%E4%B8%80%E6%9D%A1%E6%99%AE%E9%80%9A%E4%BA%BA%E4%B9%9F%E8%B7%91%E5%BE%97%E9%80%9A%E7%9A%84%E8%87%AA%E5%AD%A6%E8%B7%AF%E7%BA%BF%E5%9B%BE_%E5%9B%BE%E7%89%87/_1775634882741.jpg)**
**第 2 天自查练习：**
* 用 numpy 写一个简单的梯度下降：拟合 y = x^2 或线性回归
* 打印每一步的 loss，观察是否下降
* 把学习率设大一点，看看会不会发散，再解释为什么
做到这些，你就已经具备理解“模型怎么学”的直觉。
### 第 3 天：概率 & 噪声
深度学习里的概率，你不用搞懂一大堆公式，只要理解这三件事：
1. 噪声（Noise）
2. 采样（Sampling）
3. Softmax 概率分布
![](%5B2026-01-14_02-15%5D%20%E4%BD%A0%E4%B8%8D%E5%AD%A6%20AI%E6%9C%AA%E6%9D%A5%E4%BA%94%E5%B9%B4%E5%87%A0%E4%B9%8E%E6%97%A0%E8%B7%AF%E5%8F%AF%E8%B5%B0%EF%BC%9A%E4%B8%80%E6%9D%A1%E6%99%AE%E9%80%9A%E4%BA%BA%E4%B9%9F%E8%B7%91%E5%BE%97%E9%80%9A%E7%9A%84%E8%87%AA%E5%AD%A6%E8%B7%AF%E7%BA%BF%E5%9B%BE_%E5%9B%BE%E7%89%87/_1775634882999.jpg)
**第 3 天自查练习：**
* 用 numpy 生成 10000 个高斯随机数并画直方图
* 手写一个 softmax 函数，检验输出是否为 1
* 在同一个 logits 上，用不同 temperature 做 softmax，看输出分布变化

## 阶段 2：深度学习基础（3 天搞定）
目标：理解“神经网络本质是什么 + 训练流程 + 最小 CNN”，不再被“黑箱”吓到。
### 第 1 天：神经网络本质 = 函数逼近器
**学习路径**
1. 略读《Dive into Deep Learning》前 3 章或类似中文资料
2. 用 PyTorch 实现一个两层 MLP 做一个玩具二分类
3. 改几次结构，看 loss 和准确率如何变化
依然是一张图解决问题
**![](%5B2026-01-14_02-15%5D%20%E4%BD%A0%E4%B8%8D%E5%AD%A6%20AI%E6%9C%AA%E6%9D%A5%E4%BA%94%E5%B9%B4%E5%87%A0%E4%B9%8E%E6%97%A0%E8%B7%AF%E5%8F%AF%E8%B5%B0%EF%BC%9A%E4%B8%80%E6%9D%A1%E6%99%AE%E9%80%9A%E4%BA%BA%E4%B9%9F%E8%B7%91%E5%BE%97%E9%80%9A%E7%9A%84%E8%87%AA%E5%AD%A6%E8%B7%AF%E7%BA%BF%E5%9B%BE_%E5%9B%BE%E7%89%87/_1775634883259.jpg)**
**自查练习：**
* 用 PyTorch 写一个两层 MLP，对一个二维玩具数据做分类
* 尝试用 ReLU / Sigmoid / Tanh，观察训练速度和最终效果
* 画出训练过程中的 loss 曲线
如果你能做到这些，恭喜，你已经跨过了“神经网络是黑魔法”的门槛。
### 第 2 天：前向传播 → 损失函数 → 反向传播
核心目标：你要能自己从 0 写出一段「训练循环」。
**典型训练循环大概长这样：**
![](%5B2026-01-14_02-15%5D%20%E4%BD%A0%E4%B8%8D%E5%AD%A6%20AI%E6%9C%AA%E6%9D%A5%E4%BA%94%E5%B9%B4%E5%87%A0%E4%B9%8E%E6%97%A0%E8%B7%AF%E5%8F%AF%E8%B5%B0%EF%BC%9A%E4%B8%80%E6%9D%A1%E6%99%AE%E9%80%9A%E4%BA%BA%E4%B9%9F%E8%B7%91%E5%BE%97%E9%80%9A%E7%9A%84%E8%87%AA%E5%AD%A6%E8%B7%AF%E7%BA%BF%E5%9B%BE_%E5%9B%BE%E7%89%87/_1775634883536.jpg)
你需要搞懂：
* 前向传播：输入 → 一层层算 → 输出预测 ŷ
* 损失函数：衡量 ŷ 和真实 y 差多远
* 反向传播：PyTorch 根据计算图，自动求出每个参数的梯度
* 优化器：拿着梯度更新参数（SGD、Adam 等）
你不需要手写链式法则推导，只要会用就行。
**自查练习：**
* 自己从空白文件写出一个最小训练循环（不能 copy paste）
* 对比 SGD 和 Adam： 换同样学习率，看哪个收敛更快
* 换不同学习率，观察是否发散
* 能解释一句话：为什么学习率过大会发散？

### 3.3 Transformer：现在所有 LLM 的骨架
这是全篇里最值得花时间的部分。

Attention(Q,K,V) = softmax(QK^T / sqrt(d\_k)) V

### 4.1 微调：让模型“偏向你”
几种常见方式：
* SFT（监督微调）：喂给模型「问题 + 标准答案」
* LoRA：在大权重矩阵旁边加一个小的可训练低秩矩阵 BA
* QLoRA：先把原始权重量化成 4bit，再挂 LoRA，提高显存利用
什么时候用微调？
* 你的任务非常垂直（例如某行业专业问答）
* RAG 无法很好解决生成风格 / 推理逻辑问题
* 你希望模型“说话方式”有固定风格（品牌语气）
### 4.2 RAG（检索增强生成）：让模型“知道你们公司的事”
RAG 大概长这样：
问题 → Embedding → 检索相关文档 → 拼成 Prompt → 喂给 LLM → 回答
要做的工程工作主要集中在：
* 文档清洗和 chunk 切分
* 选择 embedding 模型
* 选向量数据库（FAISS / Milvus / pgvector 等）
* Rerank + Query Rewrite 提升质量
* 加上缓存和日志，做成真正可用的系统
现实里，80% 公司级问答 / 知识库 / 内部助手类需求，RAG 就够了。
### 4.3 Agent：让模型不止“会说”，而是“会去做”
Agent 本质上是：
LLM + 一堆工具（Tool） + 一点点规划能力
它通常包含几个组件：
* Planner（规划步骤）
* Tools（执行动作，比如搜索、调用 API、跑代码）
* Memory（记住之前的关键信息）
* Executor（真正去跑）
* Reflection（复盘 & 自我修正）
你可以从最简单的开始：
* 写一个「自动写日报」 Agent： 调用日历 / 任务管理 API
+ 汇总今天事件
+ 生成日报草稿
* 再慢慢升级到： 自动分析 Excel
+ 自动拉取数据 + 生成报告
+ 自动查文献 + 写初稿
做到这个阶段，你已经从“玩玩大模型”变成了“用大模型搞自动化系统”的人。

# 如何利用大模型搭建本地知识库？

---

**去年一年我都在做RAG企业落地，用的是RAGFlow+[vllm](https://zhida.zhihu.com/search?content_id=776200148&content_type=Answer&match_order=1&q=vllm&zhida_source=entity)（bge-m3+reranker）+自研的文本分块算法，应用在垂直领域知识问答的效果非常好。**
大家已经说了很多针对企业的知识库搭建，这里我想说说，
## **针对个人，如何搭建自己的本地知识库，让你的小龙虾更懂你。**
做这个针对个人的RAG，起因是嫌手里的OpenClaw小龙虾写出来的东西没有“我”的味道，即使给它用了诸如[Humanizer](https://zhida.zhihu.com/search?content_id=776200148&content_type=Answer&match_order=1&q=Humanizer&zhida_source=entity)之类的人味润色技能。
为了解决这个问题，**我把我本地的Obsidian知识库连上OpenClaw，再配上本地嵌入模型，现在小龙虾产出已经很有“我”的味道了。**
## **整体思路**
1. **Obsidian本地知识库（里面是我上百篇文章，markdown格式）**
2. **Ollama本地嵌入模型做向量化（我选的bge-m3，体量小，中文效果好，cpu也能跑，就是慢了点）**
**为什么选知识库+嵌入模型的设计？**
* 为了让虾虾们更懂我，我把以前的文章放到Obsidian里，作为知识库
* 为了让虾虾们更好地检索知识，本地部署了bge-m3嵌入模型（效果比较好），然后设置hybrid混合检索
**什么选Obisidian和本地部署方式？**
* 知识库你用什么都行，我用的Obsidian，markdown强支持，加上openclaw记忆机制只检索.md文档，所以结合起来蛮好用。
* **嵌入模型是用来把文本转换成向量，实现语义搜索的，本地嵌入模式允许用户在不依赖外部 API 的情况下运行向量搜索，这样搞比较省钱且保护你的隐私**，另外，嵌入模型很小，仅CPU也能跑起来。我自己用的是bge-m3模型，体积小效果好，中文支持非常棒。

### Obsidian知识库构建
这一步没啥技术含量，就是简单的下个适配你操作系统的app，然后创建个装你知识库的文件夹，记住路径，完事儿。
下载好之后，在Obsidian里新建一个本地仓库（就是你的本地文件夹），把你想让小龙虾了解的信息都在这个文件夹里（markdown格式）。
**记住你的本地仓库路径哦，比如`/home/admin/Documents/knowledge-base`**
这是我自己的知识库，可以用知识图谱查看知识之间的关系。

### 本地嵌入模型部署
**第一步：安装Ollama**
![](%5B2026-04-25_14-56%5D%20%E5%A6%82%E4%BD%95%E5%88%A9%E7%94%A8%E5%A4%A7%E6%A8%A1%E5%9E%8B%E6%90%AD%E5%BB%BA%E6%9C%AC%E5%9C%B0%E7%9F%A5%E8%AF%86%E5%BA%93%EF%BC%9F_%E5%9B%BE%E7%89%87/_1777143633363.jpg)
![](data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='518' height='408'></svg>)
Ollama是一个本地大模型管理工具，一键就能安装运行嵌入模型：
```
curl -fsSL https://ollama.com/install.sh | bash
# 验证安装成功
ollama --version
```
**第二步：下载bge-m3嵌入模型**
```
ollama pull bge-m3
```
**如果国内网络下ollama pull很慢的话**
去ModelScope下载对应的GGUF模型文件，本地导入就行，首选第一种方法：
```
# 安装modelscope，下载模型到本地
pip install modelscope
modelscope download --model gpustack/bge-m3-GGUF/bge-m3-FP16.gguf --local_dir /usr/share/ollama/.ollama/models
# 创建Modelfile，写入模型路径
echo "FROM /usr/share/ollama/.ollama/models/bge-m3-FP16.gguf" > /usr/share/ollama/.ollama/models/Modelfile
# 导入模型到Ollama
ollama create bge-m3 -f /usr/share/ollama/.ollama/models/Modelfile
# 运行模型
ollama run bge-m3
# 查看本地已下载模型
ollama list
# 查看模型运行情况
ollama ps
```
**第三步：安装node-llama-cpp依赖**
本地嵌入需要node-llama-cpp库支持：
```
npm install -g node-llama-cpp
node-llama-cpp --version
# 输出版本号说明安装成功
```
**第四步：配置OpenClaw使用本地嵌入模型**
修改 `~/.openclaw/openclaw.json`，添加以下配置：
```
"agents": {
  "defaults": {
    "memorySearch": {
      "provider": "local",
      "model": "bge-m3-q2:latest",
      "local": {
        "modelPath": "/usr/share/ollama/.ollama/models/bge-m3-Q2_K.gguf",
        "modelCacheDir": "/usr/share/ollama/.ollama/models"
      },
      // 开启混合搜索，语义+关键词匹配，准确率更高
      "query": {
        "hybrid": {
          "enabled": true,
          "vectorWeight": 0.7, // 语义匹配权重70%
          "textWeight": 0.3, // 关键词匹配权重30%
          "candidateMultiplier": 3
        }
      },
      // 把你的个人知识库路径加在这里，支持多个路径
      "extraPaths": ["/home/你的用户名/Documents/你的Obsidian仓库路径"],
      // 开启缓存，提升搜索速度
      "cache": {
        "enabled": true,
        "maxEntries": 10000
      }
    }
  }
}
```
**第五步：验证嵌入模型配置情况**
```
openclaw gateway restart
openclaw memory status --deep
```

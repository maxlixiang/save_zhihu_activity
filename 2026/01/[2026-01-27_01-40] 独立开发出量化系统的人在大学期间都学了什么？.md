# 独立开发出量化系统的人在大学期间都学了什么？

---

其实门槛没那么高。从技术实现的角度来说，掌握 [Python](https://zhida.zhihu.com/search?content_id=754147948&content_type=Answer&match_order=1&q=Python&zhida_source=entity) + [MySQL](https://zhida.zhihu.com/search?content_id=754147948&content_type=Answer&match_order=1&q=MySQL&zhida_source=entity) 这两项核心工具就基本够用了，现在AI也很方便，有什么不会的直接问就好了。
我这边的运行流程是这样的：
1. Python 调用数据接口获取实时行情（我的数据来源基本是从[Akshare](https://zhida.zhihu.com/search?content_id=754147948&content_type=Answer&match_order=1&q=Akshare&zhida_source=entity)/Tushare/**[Futu](https://zhida.zhihu.com/search?content_id=754147948&content_type=Answer&match_order=1&q=Futu&zhida_source=entity)**这三个接口来的，我主要是Futu）；
2. 数据存入 MySQL 数据库，所有指标计算与选股逻辑判断都在数据库内处理；
3. Python 根据选股结果，通过 [QMT](https://zhida.zhihu.com/search?content_id=754147948&content_type=Answer&match_order=1&q=QMT&zhida_source=entity) 执行自动下单。
上面是工程实现层面的东西。其实**真正核心的部分其实在于选股逻辑**：这个就需要你学习基础的金融市场知识，理解交易机制与常用指标，你得思考**怎么样找到影响股价的关键因子**，网上那些烂大街的双均线之类的策略就算了。这部分还会涉及到一些统计学知识，比如你可以使用[相关性分析](https://zhida.zhihu.com/search?content_id=754147948&content_type=Answer&match_order=1&q=%E7%9B%B8%E5%85%B3%E6%80%A7%E5%88%86%E6%9E%90&zhida_source=entity)等方法，初步判断你的哪个指标对股票涨跌的影响更显著。量化的优势就是对数据的利用效率，这个市场可以赚钱的模式太多了，吃透一种就够了，加油少年 。

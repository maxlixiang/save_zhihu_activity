Claude Code 高手的9条朴素技巧  
Anthropic 工程师 Boris Cherny 被称为“Claude Code 之父”，他分享了自己使用 Claude Code 的 9 条实战技巧——没有炫技，全是朴素但高效的实践。  
1. \*\*别迷信最佳实践\*\*：Claude Code 开箱即用，适合自己的节奏最重要。  
 2. \*\*多 Agent 并行\*\*：同时开十几个任务，让 AI 自主执行，你只需在关键节点介入。  
 3. \*\*坚持用 Opus 4.5 + thinking 模式\*\*：虽然慢一点，但纠错少、工具调用准，综合效率更高。  
 4. \*\*用 .claude 文件积累项目记忆\*\*：团队共享“AI 项目说明书”，每次纠错都变成资产。  
 5. \*\*先 Plan 再编码\*\*：Shift+Tab 进入 Plan 模式，对齐思路再动手，避免返工。  
 6. \*\*自动化重复劳动\*\*：斜杠命令 + 子 Agent，把高频操作固化下来。  
 7. \*\*安全集成外部工具\*\*：通过 MCP 协议连接 Slack、BigQuery、Sentry，Claude 成为全能助手。  
 8. \*\*长任务交给 AI 自主验证\*\*：用 Hooks 或 ralph-wiggum 插件实现自动迭代。  
 9. \*\*最关键：给 Claude 验证能力\*\*：能自测的 AI，产出质量提升 2–3 倍。  
高手无招胜有招——真正厉害的不是配置多复杂，而是理解逻辑、组合得当。新手不妨从并行、规划、.claude 和验证这四点开始。

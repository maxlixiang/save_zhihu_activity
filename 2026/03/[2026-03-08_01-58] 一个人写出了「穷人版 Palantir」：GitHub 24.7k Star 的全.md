功能密度高到离谱。挑 4 个最狠的说。
### **1. 3D 地球：40+ 数据图层**
deck.gl + MapLibre GL JS，WebGL 渲染，60fps。往地球上能叠这些东西：
* • 冲突区域（UCDP + ACLED 双源交叉验证）
* • 210+ 军事基地、核设施、83 个战略港口
* • 军事飞行实时追踪（ADS-B）+ 海上船舶监控（AIS）
* • 海底光缆及健康状态、油气管道、111 个 AI 数据中心
* • GPS/GNSS 干扰区（H3 六边形网格）、NASA 卫星火点
* • 网络威胁 IOC（C2 服务器、钓鱼、恶意 URL 的地理定位）
* • 19 条全球贸易航线、107 个机场延误/关闭状态
不是 5 个、不是 10 个——**40+ 个可切换图层**，每个背后都接着真数据源。全打开的话，地球会变成一颗发光的刺猬。
### **2. AI 情报分析：4 级降级，断不了线**
AI 摘要走一条 4 级降级链：
```
Ollama（本地）→ Groq（云端）→ OpenRouter（云端）→ 浏览器端 T5（Transformers.js）
```
每级 5 秒超时，挂了自动跳下一级。最极端的情况——断网、没 API Key、云端全崩——**浏览器里的 T5 照样能出摘要**。
不过真正让我意外的是 **Headline Memory**：浏览器端跑 ONNX 嵌入模型，把每条新闻标题存进 IndexedDB 向量库（5,000 条封顶，LRU 淘汰），之后你能用自然语言搜历史新闻。一整条 RAG 管线在浏览器里跑，**数据不出本机**。
还有个 AI 推演面板——你输入"未来 24 小时中东会怎样"，系统自动把最新 15 条新闻灌进上下文，AI 给你一份近期预测。靠不靠谱另说，但这个功能设计是真大胆。

### **4. 三级隐私：数据可以完全不出机器**
做 OSINT 的人大概最在意这个——数据到底出不出机器。三级选择：
| 级别 | 怎么跑 | 数据出不出机 |
| --- | --- | --- |
| Level 1 | Web 版 | 出 |
| Level 2 | 桌面端 + 云 API | 部分出 |
| Level 3 | 桌面端 + Ollama | 不出 |
桌面端拿 Tauri 写的（macOS/Windows/Linux），API Key 存 OS 钥匙串，不落盘。Ollama 本地跑，摘要和威胁分类全在你机器上算。60+ 个 API handler 在本地 Sidecar 里跑，断网照样用。
大多数 AI 产品还在琢磨怎么多捞你的数据。World Monitor 在琢磨怎么让数据不出你的机器。

### **其他亮点**
![](%5B2026-03-08_01-58%5D%20%E4%B8%80%E4%B8%AA%E4%BA%BA%E5%86%99%E5%87%BA%E4%BA%86%E3%80%8C%E7%A9%B7%E4%BA%BA%E7%89%88%20Palantir%E3%80%8D%EF%BC%9AGitHub%2024.7k%20Star%20%E7%9A%84%E5%85%A8_%E5%9B%BE%E7%89%87/_1775633275195.jpg)
上面 4 个最核心。下面一句话过：
* • **国家不稳定指数（CII）**：给有数据的国家实时算 0–100 不稳定分。乌克兰常年 55+，瑞士永远绿灯。民主国家抗议用对数计分（法国黄马甲不触发警报），威权国家用线性（一次街头抗议就是大事）
* • **19 种语言 + RTL**：切韩语，自动启用联合通讯社的 RSS；切阿拉伯语，布局变右到左
* • **Proto-First API**：22 个服务域，Protocol Buffers 定义，自动生成 TypeScript 客户端。`api.worldmonitor.app` 公开可用，不注册直接 curl
* • **PWA 离线**：可装到桌面，地图 tile 离线缓存 500 张
* • **7 信号宏观雷达**：JPY 流动性、BTC 趋势、Fear & Greed 等 7 个信号，给 BUY/CASH 判断（我点开看了一眼，最近一直显示 CASH——不知道该紧张还是庆幸）

### **怎么用**
### **秒开（0 门槛）**
打开 [https://worldmonitor.app](https://link.zhihu.com/?target=https%3A//worldmonitor.app) 就完了。不注册、不装东西、不要 API Key。地图、静态图层、浏览器端 ML——打开就能跑。
### **进阶（5 分钟）**
1. 1. **下桌面端**：GitHub Release 有 macOS/Windows/Linux 安装包
2. 2. **配 Ollama**：本地跑 LLM，摘要在你机器上生成
3. 3. **按需开 API Key**：Groq（免费 14,400 请求/天）、FRED（经济数据）、NASA FIRMS（卫星火点），想用哪个开哪个
### **极客（20 分钟）**
```
git clone https://github.com/koala73/worldmonitor.git
cd worldmonitor
npm install
cp .env.example .env.local
vercel dev
```
打开 `localhost:3000`，一套完整的态势感知系统就在你面前。改数据源、加面板、接自己的情报管道——随便折腾。
有个坑提前说：`npm run dev` 只启动前端，新闻和 API 面板全空。得用 `vercel dev`（先装 Vercel CLI）才能跑完整 API 层。
AGPL-3.0 协议。通过网络对外提供服务，你的改动要开源。本地自用，不限。

### **值不值得**
### **好在哪**
**功能密度没对手**。不是替代 FlightRadar24 或 MarineTraffic 中的某一个——是把十几个工具的核心能力塞进一个界面。新闻聚合、3D 地球、AI 情报、军事追踪、海事监控、金融雷达、网络威胁、气候异常、预测市场。我翻了一圈，没找到第二个开源项目一个代码库搞定这些。
**架构不是玩具**。三层缓存、请求去重防雪崩、负缓存防击穿、per-feed 熔断器、Welford 在线算法做异常基线——1,600+ commit，43 个 Release，扛过真实流量的系统。
**隐私有诚意**。说实话，"我的查询行为不被第三方看到"——对 OSINT 从业者来说，这一条就够了。Level 3 做到了。完全不出机器。
### **差在哪**
**信息过载**。47 个面板 + 40+ 图层，你第一次打开大概率会蒙。不是那种"5 秒看懂"的东西，有学习曲线。
**一个人扛**。核心开发就 Elie Habib 一人。他不干了，项目就悬。好在 AGPL-3.0 允许 fork，代码结构也清晰。
还有两个小问题：手机别想——小于 768px 直接弹警告；部分高级功能像军事飞行（OpenSky）、冲突数据（ACLED）需要单独注册免费 API。不影响核心体验，但得提前知道。

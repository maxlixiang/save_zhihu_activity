# 九年后_想法

32 万星的 GitHub 仓库，全网免费 API 都在这里了。  
它叫 Public APIs，1500 多个免费端点，每条都注明了认证类型、HTTPS 状态、CORS 支持，点进去直达文档。  
覆盖范围很广，金融、加密货币、股票、银行数据，天气、地图、地理编码、交通，机器学习、OCR、情感分析，音乐、电影、动漫、游戏，政府数据集、新闻、健康、安全。  
说句不好听的，市面上一半标价 99 美元每月的工具，背后调的就是这个仓库里的免费端点，加了个仪表板卖回给你。独立开发者用这里的免费 tier 就能推出完整产品，而很多新人还在给 RapidAPI 交订阅费，被人卖了还帮人数钱。  
323K stars，MIT 协议，100% 开源，没有套路，没有付费墙，没有隐藏条件，所有人都可以免费商用。

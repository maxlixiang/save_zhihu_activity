### **第二步：AI编写代码**
猫哥目前偏向做日线级别的量化研究，所以这里只创建日线的行情数据表，直接让Claude Code帮我们编写数据下载和保存的代码，提示词：

写个python代码，将 全部股票 的 1d 日线行情数据（2015年1月1日至今），保存到 mysql数据库，quant_data.kline_data

没一会，代码就写好了，这里展示一下SQL代码的部分：
```
CREATE TABLEIFNOTEXISTS kline_data (
    idBIGINT AUTO_INCREMENT PRIMARY KEY,
    stock_code VARCHAR(20) NOTNULLCOMMENT'股票代码',
    trade_date DATENOTNULLCOMMENT'交易日期',
    periodVARCHAR(10) NOTNULLDEFAULT'1d'COMMENT'周期类型',
    open_price DECIMAL(10,4) NOTNULLCOMMENT'开盘价',
    high_price DECIMAL(10,4) NOTNULLCOMMENT'最高价',
    low_price DECIMAL(10,4) NOTNULLCOMMENT'最低价',
    close_price DECIMAL(10,4) NOTNULLCOMMENT'收盘价',
    volume BIGINTNOTNULLDEFAULT0COMMENT'成交量',
    amount DECIMAL(20,4) NOTNULLDEFAULT0COMMENT'成交额',
    pre_close DECIMAL(10,4) DEFAULTNULLCOMMENT'前收盘价',
    suspend_flag TINYINTDEFAULT0COMMENT'停牌标记 0-正常 1-停牌 -1-当日起复牌',
    created_time TIMESTAMPDEFAULTCURRENT_TIMESTAMPCOMMENT'创建时间',
    updated_time TIMESTAMPDEFAULTCURRENT_TIMESTAMPONUPDATECURRENT_TIMESTAMPCOMMENT'更新时间',
    UNIQUEKEY uk_stock_date_period (stock_code, trade_date, period),
    KEY idx_stock_code (stock_code),
    KEY idx_trade_date (trade_date),
    KEY idx_created_time (created_time)
) ENGINE=InnoDBDEFAULTCHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='K线行情数据表';
```
**亮点解析：**
* ✨ **精确的数据类型**：价格用DECIMAL(10,4)，避免浮点误差
* 🚀 **完美的索引设计**：股票代码+日期的联合唯一索引
* 🛡️ **防重复机制**：UNIQUE KEY确保数据不重复
* 📝 **详细的注释**：每个字段都有清晰说明
## **多进程下载代码的技术亮点**
### **1. 多进程并行下载**
为了提高数据下载速度，猫哥使用了多进程的技术，设置4个进程比单进程下载快3-4倍，且提高稳定性，单个进程崩溃不影响其他进程。
```
def download_stock_group_process(stock_group: list, group_id: int, start_date: str, end_date: str, is_first: bool):
    """多进程下载函数 - 每个进程处理一组股票"""
    # 使用ProcessPoolExecutor实现真正的并行
    with ProcessPoolExecutor(max_workers=MAX_WORKERS) as executor:
        future_to_group = {
            executor.submit(download_stock_group_process, stock_groups[i], i + 1, START_DATE, END_DATE, IS_FIRST_DOWNLOAD): i + 1
            for i in range(total_groups)
        }
```
### **2. 完善的错误处理**
在每个环节，加入异常处理函数，方便后续的问题排查。
```
# 每个环节都有异常处理
try:
    xtdata.download_history_data(stock_code=stock_code, period="1d", start_time=start_date, end_time=end_date)
    success_count += 1
except Exception as e:
    logger.error(f"下载股票 {stock_code} 失败: {e}")
    failed_stocks.append(stock_code)
    continue
```
### **3. 增量下载支持**
```
# 首次下载和增量下载自动切换
if IS_FIRST_DOWNLOAD:
    # 指定时间范围下载
    xtdata.download_history_data(stock_code=stock_code, period="1d", start_time=start_date, end_time=end_date)
else:
    # 增量下载，只下载新数据
    xtdata.download_history_data(stock_code=stock_code, period="1d", incrementally=True)
```

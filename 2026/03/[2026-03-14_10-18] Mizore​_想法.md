# Mizore​_想法

---

用了半年Claude Code， 我把我的一键配置开源了  
刚开始用 Claude Code 的时候，每次新项目都要重新配CLAUDE.md，skills一个个装，犯过的错下次照样犯，连 context 用了多少都不知道。  
后来我想，这些事情为什么不能自动化？  
于是花了几天，把最佳实践全部沉淀成了一个开源项目：  
✅ 19 个插件一行命令装好，不用再一个个找  
✅ 被纠正的错误自动记录，Claude 会越用越聪明  
✅ 状态栏实时显示用量，项目目录、conda环境、git分支、context和5h用量一目了然  
✅ Claude × Codex 跨模型代码审查，三种批判视角  
✅ Python / TS / Go 编码规则内置，不用每次从零写  
✅ 升级时智能合并，不会覆盖你的配置  
还内置了一个论文阅读技能 📄 给 Claude 一个 arXiv 链接，它会自动用 ar5iv 抓 HTML 版本，Playwright 截取关键图表，然后输出结构化 Markdown  
笔记——问题、方法、实验、核心洞见，一篇论文几分钟就读完。科研党和 AI 从业者可以试试，比自己啃 PDF 快太多了。

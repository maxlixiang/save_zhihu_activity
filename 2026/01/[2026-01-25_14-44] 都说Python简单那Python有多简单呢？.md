# 都说Python简单，那Python有多简单呢？

---

我先学的C和[C++](https://zhida.zhihu.com/search?content_id=759342848&content_type=Answer&match_order=1&q=C%2B%2B&zhida_source=entity)，那时候想找一门脚本来学，用来生成C++代码，我花一个下午看完了python的基本教程，然后就写出了一个生成读配置文件的代码的工具。
这些年学过十几门编程语言，最简单的是[lua](https://zhida.zhihu.com/search?content_id=759342848&content_type=Answer&match_order=1&q=lua&zhida_source=entity)，其次是python。lua真的可以在一个下午学完，python一个下午至少可以学完一半，学到函数的部分，然后那种几百行以内的脚本用几个函数写出来就行了。
而且即使几十行以内也可以写出很多有用的脚本。我很早就开始使用[linux](https://zhida.zhihu.com/search?content_id=759342848&content_type=Answer&match_order=1&q=linux&zhida_source=entity)，从网上下载的很多文本和源码都是在windows下面写的，编码是[gbk](https://zhida.zhihu.com/search?content_id=759342848&content_type=Answer&match_order=1&q=gbk&zhida_source=entity)，于是我就写了个python脚本进行编码转换，核心的代码就这样：
```
# 读取GBK内容
with open(original_file, 'r', encoding='gbk', errors='ignore') as f:
    content = f.read()
# 写入UTF-8内容
with open(new_file, 'w', encoding='utf-8') as f:
    f.write(content)
```
当然在这之前可以先判断是否gbk编码，后来我还更新了这个脚本，可以用来对一个目录下面的所有文件进行批量转换。后来我还把这个脚本发给几个同事用过，他们写的代码编码总是gbk的。当然也可以把这个脚本放在git的[预提交钩子](https://zhida.zhihu.com/search?content_id=759342848&content_type=Answer&match_order=1&q=%E9%A2%84%E6%8F%90%E4%BA%A4%E9%92%A9%E5%AD%90&zhida_source=entity)里面执行，这样就没人会忘记了。
总之python可以做很多实用的事情，并且都很简单。
python其它的功能像面向对象、模块与包、元类之类的功能，这些可以算python的另一半，在以后需要用到的时候再学习即可。

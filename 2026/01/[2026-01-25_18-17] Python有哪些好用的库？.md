# Python有哪些好用的库？

---

作为一个常年写 Python 的人，我的体会是：好用的库分两种，一种是“工具型”，帮你快速解决通用问题；另一种是“领域型”，针对某个特定场景特别强大。下面我按**入门必备库 / 提升效率库 / 高阶领域库**三层来聊聊我自己常用、且值得推荐的库。
## 一、入门必备（刚学 Python 时就能用）
这些库是我最推荐新手先接触的——安装简单、功能直观，用一次就能感受到“Python 真好用”。
**1. tqdm** – 进度条神器  
当你的程序需要跑一大堆循环时，如果屏幕一直没反应，很容易怀疑人生。`tqdm` 能一行代码加上优雅的进度条：
```
from tqdm import tqdm
for i in tqdm(range(1000000)):
    pass
```
我第一次用它是在批量下载几千张图片的时候，终于能知道“还有多久跑完”，再也不用盯着 CPU 占用瞎猜。
**2. requests** – 人类友好的 HTTP 库  
调接口、爬网页时必备，比 `urllib` 直观太多：
```
import requests
res = requests.get("https://api.github.com")
print(res.json())
```
比如你想批量下载一组网络图片、或者抓取一个网页的标题，requests 都能一行搞定。
**3. pathlib** – 文件路径优雅操作  
以前用 `os.path` 写文件路径拼接，Windows 和 Linux 下的斜杠还不一样，容易出 bug。`pathlib` 直接面向对象操作：
```
from pathlib import Path
p = Path("data") / "test.txt"
print(p.exists())
```
我常用它来批量遍历文件夹、筛选出特定格式的文件，比如 `list(Path(".").glob("*.jpg"))` 就能找到所有 jpg 图片。
**4. openpyxl** – Excel（xlsx）读写神器  
如果你工作中需要批量处理 Excel 表格，比如合并多份报表、自动生成每月的统计表，`openpyxl` 可以帮你省掉很多重复劳动：
```
from openpyxl import Workbook
wb = Workbook()
ws = wb.active
ws["A1"] = "Hello World"
wb.save("demo.xlsx")
```
我有个同事就是用它把 300 份门店日报合成一份总表，每天节省一个多小时。
**5. matplotlib** – 万能画图库  
虽然 API 有点“老派”，但它是 Python 可视化的基石，几乎所有高级画图库底层都是它：
```
import matplotlib.pyplot as plt
plt.plot([1, 2, 3], [2, 4, 6])
plt.show()
```
哪怕你只是想画个简单的折线图统计销售额变化，它都能帮你搞定。
**建议**：入门阶段，不用一口气学完全部功能。找一个小需求，比如“批量重命名文件”、“下载一批网络图片”、“画一张温度变化图”，然后用这些库去完成。带着目标去学，记得更牢，也更有成就感。
## 二、提升效率（工作中常驻）
当你已经能用 Python 写小项目，就可以考虑升级装备，用这些库来让代码更高效、可维护性更高。它们不仅能减少重复劳动，还能帮你写出更专业的产出。
* **pandas** – 数据分析界的“瑞士军刀”，处理 CSV、Excel、SQL 查询结果都飞快。
```
import pandas as pd
df = pd.read_csv('sales.csv')
print(df.groupby('region')['revenue'].sum())
```
*应用场景*：销售报表汇总、日志分析、数据清洗。
* **numpy** – 高效的数值计算库，也是 pandas 的底层基石。
```
import numpy as np
arr = np.array([1, 2, 3])
print(arr * 2)  # [2 4 6]
```
*应用场景*：矩阵运算、科学计算、机器学习前处理。
* **loguru** – 让日志记录变得优雅、好读，调试时的好帮手。
```
from loguru import logger
logger.info("程序启动")
```
*应用场景*：线上脚本日志、调试错误信息。
* **typer / [click](https://zhida.zhihu.com/search?content_id=741570433&content_type=Answer&match_order=1&q=click&zhida_source=entity)** – 命令行工具开发神器，让你五分钟做出一个 CLI。
```
import typer
def hello(name: str):
    print(f"Hello {name}")
typer.run(hello)
```
*应用场景*：批量处理脚本、内部小工具。
* **schedule / [apscheduler](https://zhida.zhihu.com/search?content_id=741570433&content_type=Answer&match_order=1&q=apscheduler&zhida_source=entity)** – 定时任务，比 crontab 更灵活。
```
import schedule, time
schedule.every(10).seconds.do(lambda: print("任务执行"))
while True:
    schedule.run_pending()
    time.sleep(1)
```
*应用场景*：数据同步、定期备份、定时提醒。
* **rich** – 彩色终端输出的“美化大师”，还能渲染表格、Markdown、进度条。
```
from rich.console import Console
console = Console()
console.print("[bold green]任务完成[/]")
```
*应用场景*：命令行工具美化、日志增强、进度提示。
**建议**：在公司业务脚本、数据分析、自动化任务中，用它们替代“手写轮子”，不仅能少踩坑，还能让你的代码质量和产出速度直线上升。
## 三、高阶领域（按方向深入）
当你熟悉了 Python 的基础语法和常用工具库，就会发现——不同应用方向对技术栈的要求差别很大。想做数据分析的人和想做 Web 开发、机器学习的人，走的路完全不同。
所以，高阶阶段最适合 **按方向深入**，先在一个领域里打出自己的“技能树”，再视情况横向扩展。  
下面是几个常见方向和代表性库：
### **3.1 数据分析 / 可视化**
适合喜欢与数据打交道、挖掘趋势与规律的人。重点是用高效的工具处理数据，再用可视化让结果“一图胜千言”。
* **seaborn** —— 高颜值统计图表库，风格优雅、上手快。
```
import seaborn as sns
tips = sns.load_dataset("tips")
sns.barplot(x="day", y="total_bill", data=tips)
```
*(轻松画出分组柱状图，比 matplotlib 美观很多)*
* **plotly** —— 支持交互式图表，可直接在浏览器展示。
```
import plotly.express as px
tips = px.data.tips()
fig = px.scatter(tips, x="total_bill", y="tip", color="day")
fig.show()
```
* **polars** —— 基于 Rust 实现的 DataFrame 库，处理大数据超快，性能媲美 Spark。
```
import polars as pl
df = pl.read_csv("big_data.csv")
print(df.filter(pl.col("value") > 1000).head())
```
### **3.2 机器学习 / AI**
如果你想让计算机“学会”做决策，这就是你的主场。从经典算法到深度学习，都有成熟的工具链支持。
* **[scikit-learn](https://zhida.zhihu.com/search?content_id=741570433&content_type=Answer&match_order=1&q=scikit-learn&zhida_source=entity)** —— 经典机器学习框架，涵盖分类、回归、聚类等常用算法。
```
from sklearn.linear_model import LinearRegression
X, y = [[1], [2], [3]], [2, 4, 6]
model = LinearRegression().fit(X, y)
print(model.predict([[4]]))  # [8.]
```
* **[PyTorch](https://zhida.zhihu.com/search?content_id=741570433&content_type=Answer&match_order=1&q=PyTorch&zhida_source=entity) / [TensorFlow](https://zhida.zhihu.com/search?content_id=741570433&content_type=Answer&match_order=1&q=TensorFlow&zhida_source=entity)** —— 深度学习两大阵营。  
  *(PyTorch 灵活易调试，TensorFlow 工业部署强)*
* **transformers** —— NLP 模型调用神器，支持 BERT、GPT、CLIP 等前沿模型。
```
from transformers import pipeline
summarizer = pipeline("summarization")
print(summarizer("Your long text here", max_length=20))
```
### **3.3 网络爬虫 / 自动化**
当你需要抓取互联网数据或批量操作网页，这类库会让效率翻倍。
* **[beautifulsoup4](https://zhida.zhihu.com/search?content_id=741570433&content_type=Answer&match_order=1&q=beautifulsoup4&zhida_source=entity)** —— HTML 解析利器。
```
from bs4 import BeautifulSoup
soup = BeautifulSoup("<p>Hello</p>", "html.parser")
print(soup.p.text)  # Hello
```
* **[playwright](https://zhida.zhihu.com/search?content_id=741570433&content_type=Answer&match_order=1&q=playwright&zhida_source=entity)** —— 新一代浏览器自动化，比 Selenium 更现代、更稳定。
* **[pyautogui](https://zhida.zhihu.com/search?content_id=741570433&content_type=Answer&match_order=1&q=pyautogui&zhida_source=entity)** —— 模拟鼠标键盘操作，桌面自动化神器。  
  *(比如定时自动点开应用、批量截图)*
### **3.4 Web 开发**
如果你想做网站、API 或小程序的后端，这个方向必不可少。
* **FastAPI** —— 现代化 API 框架，性能高、开发快，自带文档生成。
```
from fastapi import FastAPI
app = FastAPI()
@app.get("/")
def read_root():
    return {"Hello": "World"}
```
* **Pydantic** —— 数据校验核心工具，FastAPI 的灵魂搭档。
* **Django / Flask** —— 经典 Web 框架
+ **Django** 功能齐全，适合大项目
+ **Flask** 灵活简洁，适合小项目
## 四、学习建议
### 1. 不要一次性“啃完”
Python 生态太大，不可能一次全学。先按需求挑两三个库用起来——比如要做爬虫，就学 `requests` + `beautifulsoup4` + `tqdm`；要做数据分析，就上 `pandas` + `matplotlib` + `seaborn`。
### 2. 项目驱动学习
带着任务去学，能快速建立联系与记忆，比死记 API 高效得多。做的项目越多，对库的特性和适用场景就越熟悉。
### 3. 关注生态与趋势
Python 的优势在于生态庞大、活跃度高。养成习惯：
* **会找库**（GitHub、PyPI、Awesome-Python）
* **会读文档**（官方文档、示例、社区讨论）
* **敢试新东西**（别被旧习惯绑住）
**总结：**
* 入门阶段，靠简单好用的库建立信心；
* 中期，依赖工具库提升效率；
* 高阶阶段，按领域深耕，形成自己的技术栈。
等你用 Python 三五年后，你会发现——真正的核心技能，不是记住多少库，而是能在**不同场景下选对工具，并敢于尝试新技术**。

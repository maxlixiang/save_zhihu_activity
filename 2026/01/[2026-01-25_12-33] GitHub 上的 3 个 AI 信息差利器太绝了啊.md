相信大家也和我一样，对优质的信息源极度关注。
我一般在 **X、小宇宙播客、即刻**等平台获取最优质的信息。但是信息一般会散落在各个平台，如果能聚合推送给我就好了。

### 02、**监控热点神器**
这个叫 TrendRadar 的开源项目可以一键监控**今日头条、百度热搜、微博、抖音、知乎、B站等 35 个平台**，把分散在各个平台的热搜合并起来。
按照你关心的热度重新排序，不再被各个平台的算法牵着走。**它最大的特点是，小白也能部署成功。**
![](%5B2026-01-25_12-33%5D%20GitHub%20%E4%B8%8A%E7%9A%84%203%20%E4%B8%AA%20AI%20%E4%BF%A1%E6%81%AF%E5%B7%AE%E5%88%A9%E5%99%A8%E5%A4%AA%E7%BB%9D%E4%BA%86%E5%95%8A_%E5%9B%BE%E7%89%87/_1775634168659.jpg)
支持智能关键词筛选，比如**设置个人关键词**，比如：AI、开源，只推送相关热点，过滤无关信息，自动生成热点分析报告。
而且还能**企业微信、飞书、钉钉推送**，30 秒网页部署，1 分钟手机通知，无需编程基础。
![](%5B2026-01-25_12-33%5D%20GitHub%20%E4%B8%8A%E7%9A%84%203%20%E4%B8%AA%20AI%20%E4%BF%A1%E6%81%AF%E5%B7%AE%E5%88%A9%E5%99%A8%E5%A4%AA%E7%BB%9D%E4%BA%86%E5%95%8A_%E5%9B%BE%E7%89%87/_1775634169071.jpg)
![](%5B2026-01-25_12-33%5D%20GitHub%20%E4%B8%8A%E7%9A%84%203%20%E4%B8%AA%20AI%20%E4%BF%A1%E6%81%AF%E5%B7%AE%E5%88%A9%E5%99%A8%E5%A4%AA%E7%BB%9D%E4%BA%86%E5%95%8A_%E5%9B%BE%E7%89%87/_1775634169231.jpg)
更值得一提的是它的 AI 分析功能，**基于 MCP 协议实现了 13 种智能分析工具。**你可以直接用自然语言提问，比如查询昨天知乎的热点或分析比特币最近的热度趋势，系统就会给出相应的分析结果。
**如何部署**
很简单，直接 Fork 这个开源项目到你的 GitHub 账户。
```
开源地址：https://github.com/sansan0/TrendRadar
```
在你 Fork 后的仓库中，进入 `Settings` > `Secrets and variables` > `Actions` > `New repository secret。`
![](%5B2026-01-25_12-33%5D%20GitHub%20%E4%B8%8A%E7%9A%84%203%20%E4%B8%AA%20AI%20%E4%BF%A1%E6%81%AF%E5%B7%AE%E5%88%A9%E5%99%A8%E5%A4%AA%E7%BB%9D%E4%BA%86%E5%95%8A_%E5%9B%BE%E7%89%87/_1775634169618.jpg)
然后配置一下你想在哪个平台收热点新闻通知，比如企业微信、飞书、钉钉啥的。**可以同时配置多个平台，系统会向所有配置的平台发送通知。**
拿**企业微信机器人**举例子，你可以在 `repository` secret 配置：
* 名称：WEWORK\_WEBHOOK\_URL
* 值：你的企业微信机器人 Webhook 地址
如何获取企业微信机器人的 Webhook 地址，你可以搜一下很简单的。效果类似下图，一个 name 对应一个 `repository` secret，保存完就行。
![](%5B2026-01-25_12-33%5D%20GitHub%20%E4%B8%8A%E7%9A%84%203%20%E4%B8%AA%20AI%20%E4%BF%A1%E6%81%AF%E5%B7%AE%E5%88%A9%E5%99%A8%E5%A4%AA%E7%BB%9D%E4%BA%86%E5%95%8A_%E5%9B%BE%E7%89%87/_1775634169931.jpg)
然后在 config/config.yaml 中配置推送模式和通知选项，frequency\_words.txt 中添加你关心的关键词。
crawler.yml 中设置**推送频率，**请谨慎调整，别贪心。
**手动测试新闻推送，**进入你 Fork 的开源项目 Actions，找到 "Hot News Crawler" 的点进去
点击 "Run workflow" 按钮运行，等待 1 分钟左右数据到你企业微信上了。
```
开源地址：https://github.com/sansan0/TrendRadar
```
### 03、**AI 资讯日报**
CloudFlare-AI-Insight-Daily 是**一个基于 Cloudflare Workers 的内容聚合与生成平台。**它专门针对 AI 领域，每日自动抓取行业新闻、热门开源项目、前沿学术论文以及科技领袖的社交媒体内容。
我经常看这个，**最近什么模型发布了、什么新产品，大 V 们说了什么有意思的事情，这个开源项目都能聚合爬取。**如果使用 Folo 工具，也应该看到这个 AI Daily 的订阅源。
![](%5B2026-01-25_12-33%5D%20GitHub%20%E4%B8%8A%E7%9A%84%203%20%E4%B8%AA%20AI%20%E4%BF%A1%E6%81%AF%E5%B7%AE%E5%88%A9%E5%99%A8%E5%A4%AA%E7%BB%9D%E4%BA%86%E5%95%8A_%E5%9B%BE%E7%89%87/_1775634170096.jpg)
项目目前已经形成了完整的内容产出生态，除了生成网页版日报外，还能自动生成播客脚本，支持 RSS 订阅，甚至可以通过微信公众号每日推送，满足不同用户的内容消费习惯。
```
开源地址：https://github.com/justlovemaki/CloudFlare-AI-Insight-Daily
```
